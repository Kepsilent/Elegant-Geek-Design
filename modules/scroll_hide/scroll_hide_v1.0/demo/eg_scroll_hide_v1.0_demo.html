    极简 · 液态玻璃 · 纯白/纯黑 · 霞鹜文楷 · Lucide。

    EGD 是一套跨平台自适应设计系统（Flutter 优先，Android / iOS / Web / 桌面）。纯白为底、玻璃为质、翠绿为魂——优雅与极客的平衡。

    背景浅色纯白 #FFFFFF、夜间纯黑 #000000，不依赖彩色 / 渐变背景。液态玻璃为默认容器材质，能玻璃化的都玻璃化。

    文字层用霞鹜文楷（OFL 1.1 可商用）；图标层用 Lucide（ISC）+ SVG 实现；禁用 emoji、icon font、PNG 图标。

    对比度：正文 ≥ 4.5:1，大字 ≥ 3:1（WCAG 2.2 AA）。强调色为签名绿 #00C48C（深色 #00D494）。
