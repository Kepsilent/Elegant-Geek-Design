# EGDSticker · Sticker Decor (Atom) v1.0

## 2026-10-24 · v1.0 "Sticker Texture"

### Added
- Atom `EGDSticker`: wraps content with a "sticker" look (border + soft shadow + optional fluffy)
- Params: `borderRadius`, `borderWidth`, `borderColor`, `shadowStrength`, `fluffy`, `highlight`, `fillColor`
- Fluffy mode: layered soft shadows to simulate puffy edges (Douyin 3D soft flock sticker style)
- Minimal boundary: decoration only; content fully external
